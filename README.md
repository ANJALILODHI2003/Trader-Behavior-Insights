## Trader Behavior Insights Using Market Sentiment

This project analyzes how market sentiment (Fear & Greed Index) affects trader performance and win rates. The goal is to uncover insights that can help improve trading strategies and risk management.

## Files Included
- `Trader_Behavior_Report_Anjali_Lodhi.pdf` —  report
- `Trader_Sentiment_Analysis.ipynb` — Notebook with data processing & EDA
- `trader_sentiment_analysis_results.csv` — Merged dataset used for analysis

## Key Insights
- Higher win rate observed during Fear and Extreme Fear periods
- Neutral sentiment leads to lower performance due to unclear signals
- Extreme sentiments create higher volatility and opportunity

## Conclusion
Market sentiment provides valuable emotional signals that can help traders improve timing and strategy decision making.
